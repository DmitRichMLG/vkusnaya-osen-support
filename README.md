# Бот поддержки акции «Вкусная осень»

Тестовое задание на ИИ-инженера. Telegram-бот отвечает участникам промо-акции по правилам, сложные вопросы передаёт операторам; веб-панель для операторов; статистика. Бренд, акция и все данные вымышлены.

Стек: PHP 8.4, Laravel 13, PostgreSQL 18, Gemini, Docker Compose. Локально нужен только Docker.

## Запуск с нуля

```
cp .env.example .env      # впишите TELEGRAM_BOT_TOKEN и GEMINI_API_KEY
docker compose up
```

Первый запуск собирает образ и ставит зависимости (несколько минут). Когда в логе появится `Server running on [http://0.0.0.0:8080]`, панель доступна на http://localhost:8080. Вход: `admin@example.com` / `password` (меняются в `.env`: `OPERATOR_EMAIL`, `OPERATOR_PASSWORD`).

Всё остальное контейнер делает сам: генерирует `APP_KEY`, выполняет миграции, создаёт первого оператора.

Остановить: `docker compose down`. Снести базу: `docker compose down -v`.

## Команды

Все команды выполняются внутри контейнера:

```
docker compose exec web php artisan test          # тесты (на Postgres, база testing)
docker compose exec web ./vendor/bin/pint         # форматирование
docker compose logs -f web                        # логи
```
