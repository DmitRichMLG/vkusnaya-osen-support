Dockerfile, `compose.yaml` (postgres, web, bot), скелет Laravel 13, entrypoint (APP_KEY, migrate, seed), `.env.example`, миграции 4 таблиц акции и стандартная `users`, модели, `PromoClock`, тесты: `/up`, оператор из `.env`, инварианты БД, сдвиг времени. Готово, когда `docker compose up` с чистого клона поднимает панель.
2. **Ядро бота и первый прогон** (~2,5–3,5 ч). Промпты в `resources/prompts/`, `GeminiClient` со списком моделей, `RulesRepository`, `DrawCalendar`, `CardMasker`, `DecisionEngine` с проверкой пунктов, `bot:eval` с `--now` и сверкой с эталоном. Готово, когда отчёт прогона закоммичен.
3. **Telegram** (~1–1,5 ч). `TelegramClient`, `bot:poll`, дубли, `/start`, сообщения без текста, обращения, фраза о сроке. Готово, когда бот отвечает в живом чате.
4. **Панель** (~2,5–3,5 ч). Вход, очередь, обращение с историей и текстами пунктов, ответ, закрытие с уведомлением, решения бота, статистика.
5. **Сдача** (~2–3 ч). Правка промпта по прогону (`docs/prompt-changelog.md`), README, таблица прогона `docs/eval-report.md`, запуск с чистого клона, экспорт сессий и grep на секреты.
6. **Публикация** — выполнена 01.10.2026 вечером по команде разработчика: https://github.com/DmitRichMLG/vkusnaya-osen-support, подробности в «Что осталось разработчику», п. 3.
