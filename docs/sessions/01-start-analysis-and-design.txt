> [30.09 23:42] WSL обязательный для этого задания ?

● **Да, на этой машине WSL2 нужен.** Но только как «движок» для Docker, а не как отдельный Linux, в котором надо работать.
  
  - **Почему нужен.** Задание требует, чтобы проект поднимался командой `docker compose up`. Контейнеры (PHP, Postgres) — это Linux, поэтому на Windows Docker Desktop запускает их в виртуальной машине. Для этого у него два варианта: WSL2 или Hyper-V. Hyper-V есть только в Windows Pro и Enterprise, а у тебя **Windows 11 Home**, так что остаётся WSL2.
  - **Что именно поставлено.** Только платформа WSL2, без дистрибутива (`--no-distribution`). Ubuntu нет, заходить в Linux и что-то там настраивать не придётся. Работаешь как обычно в Windows, Docker сам использует WSL2 под капотом.
  - **Можно ли обойтись без него.** Можно поставить PHP, Composer и Postgres прямо в Windows и разрабатывать без Docker. Но тогда мы ни разу не проверим `docker compose up`, а проверяющие смотрят именно это: «запускается ли всё по README». Остальные обходные пути (своя виртуалка, удалённый Docker) сложнее и ничего не дают.
  - **Для проверяющих.** В README будет одно требование: установленный Docker с Compose. Как он поднят у них (Mac, Linux, Windows), им решать.
  - **Побочные эффекты.** Виртуальная машина WSL2 забирает часть памяти, пока работает Docker. При желании её можно ограничить файлом `.wslconfig`. Очень старые версии VirtualBox или VMware могут конфликтовать с этой платформой. После задания всё удаляется через «Программы и компоненты».
  
  Итого: оставляем и после завершения workflow перезагружаемся, как договорились.
