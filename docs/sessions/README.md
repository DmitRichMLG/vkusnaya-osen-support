## Как выгружены

Команда `/export` в Claude Code выгружает только текущую сессию, а эти сессии уже закрыты. Поэтому логи собраны скриптом `tools/export_session.py` из локальных транскриптов Claude Code (`~/.claude/projects/<папка проекта>/<id сессии>.jsonl`) в том же виде, что даёт `/export`:

- `>` — реплика разработчика, в скобках московское время;
- `●` — ответ агента или вызов инструмента, например `● Bash(Run tests)`;
- `⎿` — результат инструмента, свёрнутый до шести строк со счётчиком остальных.

Скрытые рассуждения модели, служебные записи Claude Code и ветки субагентов в лог не входят. Выгрузить другую сессию:

```
python docs/sessions/tools/export_session.py <id сессии> docs/sessions/<имя>.txt
```

## Проверка на секреты

Перед коммитом логов, как и перед любым другим коммитом:

```
python docs/sessions/tools/check_secrets.py
```

Скрипт берёт значения переменных со словами TOKEN, KEY, SECRET, PASSWORD из локального `.env` (кроме совпадающих с `.env.example`, они публичные), ищет их и общие шаблоны токена Telegram, ключей Google (`AIza…`, `AQ.…`) и `APP_KEY` во всех отслеживаемых файлах и в этой папке. Значения на экран не выводит, при находке возвращает код 1. Для этих трёх файлов он вывел «Секретов не найдено».
