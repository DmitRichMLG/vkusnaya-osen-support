# Логи сессий агента

Сюда кладутся экспорты сессий Claude Code (команда `/export`), которые сдаются вместе с проектом:

1. Старт проекта и анализ задания (шаг 0): эталон ответов, вопросы менеджеру, дизайн.
2. Реализация (шаги 1–5): каркас, ядро бота и прогоны, Telegram, панель, аудит и ревью.

Перед добавлением файла проверить, что в нём нет токена бота и ключа Gemini:

```
grep -nE '[0-9]{8,10}:[A-Za-z0-9_-]{35}|AIza[0-9A-Za-z_-]{35}' docs/sessions/*
```

Команда ничего не должна вывести.
